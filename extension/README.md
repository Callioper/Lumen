# Lumen 存档（Chrome 扩展）

把当前网页交给本机 Lumen，走和阅读器里按 `c` 一样的存档流程：整理正文 → AI 著录作者、出处、标签 → 人名库与标签库 → 图片存进库 → 写入 Obsidian → 后台补 AI 分析。

## 安装
1. Chrome 打开 `chrome://extensions`，打开右上角「开发者模式」。
2. 点「加载已解压的扩展程序」，选 Lumen 目录下的 `extension` 文件夹。

## 用法
- 快捷键 `Alt+Shift+S`，或点工具栏的扩展图标，或右键菜单「存档到 Obsidian（Lumen）」。
- 先选中一段文字再存档，选中的部分进笔记的「摘录」一节。
- 页面右下角会提示进度和结果，工具栏图标显示 ✓ 或 !。
- 改快捷键：`chrome://extensions/shortcuts`。

## 分享图
- 快捷键 `Alt+Shift+P`，或右键菜单「生成分享图（Lumen）」。
- 会在旁边打开一个 Lumen 页面：图片已自动复制，可直接粘贴；页面上还能换浅色/深色、黑体/宋体，或保存 PNG。
- 先选中一段文字，做成的是摘录卡；否则是文章卡（封面、标题、摘要、指向原文的二维码）。Lumen 里已有这篇（存档过或订阅里有同一链接）时用它的 AI 摘要。
- 存档进 Obsidian 不附分享图，两件事分开。
- 网页自带的简介太短或没有时，Lumen 用 AI 写一两句摘要；外文网页把标题和摘要译成中文（原标题作小字保留）。图先按现有内容复制，AI 的结果一到就替换并重新复制。设置 → AI → 全文翻译里可以关掉。
- 标题里的网站名会去掉；B 站以 UP 主为来源，维基百科取正文首段。

## 说明
- 需要 Lumen 在运行（127.0.0.1:8780）。扩展只连这一个地址。
- 读的是浏览器里已经渲染好的页面，所以登录后才能看的内容、公众号正文都能存。
- 存过的网页在 Lumen 侧栏「网页剪藏」分类下，按网站（公众号按号名）分源；同一网址不会重复存。
